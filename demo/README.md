# 示例内容（demo）

刚部署、还没有录入任何真实数据时，可以用这里的示例旅程把界面先撑起来：

```bash
python tools/import-demo.py
```

它做两件事：

1. 把 `photos/` 里的照片复制到 `code/uploads/`
2. 把 `trips.sample.json` 写入 `code/data/trips.json`（已存在则跳过，`--force` 才覆盖）

之后在站内用「补上一段」正常增删即可，示例旅程也能在站内删除。
**线上已有真实数据时不要加 `--force`。**

## ⚠️ 这里的数据全是编的

地名、日期都是**虚构**的（云栖镇、屿城、灯市、北岭村并不存在），
照片也刻意避开了能被认出具体地点的著名地标，只留通用的湖、海、老街、夜市、雪巷场景。
用途是让界面有内容可看，不是「某次真实旅行的记录」。
